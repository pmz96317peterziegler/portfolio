# Tech Stack

## Framework
**Astro** — static-first framework optimized for content sites. Fast builds, excellent SEO, supports component islands for interactive elements.

## CMS
**TBD** — headless CMS for managing content (projects, experience, skills, etc.) without touching code. Strong candidates: Decap CMS (free, Git-based), Contentful, or Sanity.

## Styling
**Tailwind CSS** — utility-first CSS, pairs well with Astro, good for building custom designs with smooth animation support.

## Animations
**Framer Motion** (via React island) or **CSS animations / View Transitions API** — for smooth page and element transitions inspired by mayankd.me.
