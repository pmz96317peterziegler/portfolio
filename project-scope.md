# Personal Portfolio Website

## Problem

No personal online portfolio, limiting professional visibility with recruiters and hiring managers.

## Solution

A personal website showcasing projects, work experience, skills, and education in a format that resonates with recruiters and hiring managers in the mechanical engineering field.

## Audience

Recruiters and hiring managers looking to evaluate a Mechanical Engineering Student for internships or full-time roles.

## Design Direction

- Inspired by mayankd.me — smooth animations, clean layout, image-heavy
- Dark and light mode with toggle
- Fully responsive (mobile + desktop)

## Sections

1. **Landing** — name, title, photo, brief intro
2. **About Me**
3. **Work Experience**
4. **Projects** — with images, descriptions, and links to external files (GitHub, Google Drive)
5. **Skills**
6. **Education**
7. **Contact** — LinkedIn, email, GitHub (display only, no form)

## Content Management

Content (projects, experience, etc.) managed via a headless CMS — no code changes required for updates.

## Analytics

Track visitor count and page/project engagement.

## Out of Scope

- Blog or writing section
- Contact form
- Serving large files directly (CAD, datasets) — these link out
- Custom backend or database
